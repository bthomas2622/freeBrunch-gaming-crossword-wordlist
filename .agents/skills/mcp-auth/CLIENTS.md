# Client connection references

Read exactly the reference for the current client **and surface**. These files also support the setup workflow's connection handoff without proactively invoking authentication recovery.

| Environment | Reference |
| --- | --- |
| Cursor IDE, Cursor web, or Cursor CLI | [Cursor](clients/cursor.md) |
| Claude Code CLI or the desktop Code tab | [Claude Code](clients/claude-code.md) |
| Claude Desktop Chat, Claude Code cloud agents, or claude.ai | [Claude Chat](clients/claude-chat.md) |
| ChatGPT web or desktop, Codex desktop app, Codex CLI, Codex cloud agents | [ChatGPT & Codex](clients/chatgpt-and-codex.md) |
| Any other agent, including local coding agents, or a user who does not want a plugin | [Other agents](clients/other-agents.md) |

For an ambiguous environment, establish the client before offering configuration changes.
